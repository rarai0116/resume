対外折衝・要件整理・設計・共通基盤の整備・バックエンド・一部フロントエンド開発を担当しました。

##### 取り組み
- スマートフォンアプリの開発時にチームとして自動テストやレビューをあまり行えなかった反省から、PRごとに自動テストを走らせるCIの構築し、PRレビューとあわせて開発フローに組み込んだ。
- 画面の独立性を確保するために、画面単位でZustand Storeを設置するようコードルールとして定め、再描画と修正の影響範囲を画面内に抑えた。
- 開発終盤にアプリが数GB以上のメモリを占有する場合があった。計測・分析により、高解像度画像をプロセス間でやり取りしていたことが原因と特定した。画像の受け渡し経路の再設計により、最大で約4.5GB使用していたメモリを約1.6GBに抑えた。
- 編集中に入力した文字や画像、数式（TeX）がどのように表示されるかリアルタイムに確認できない問題の解決策として、編集した部分だけ即座に更新する新しいレンダリング方式を実装した。


**使用技術**：Electron / Vite / TypeScript / Firebase / Google Cloud / GitHub Actions / pnpm / Biome
